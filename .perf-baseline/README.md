# Perf baseline history

Rolling baseline of synthetic perf measurements emitted by `tools/perf` (slice 41 R6 + post-R1–R6 follow-up plan F3, 2026-05-07).

## Files

- `history.jsonl` — one JSON object per perf run, append-only. Generated by `scripts/perf-baseline-archive.mjs`.

## Local usage

```bash
# Run perf harness
cargo run -p perf -- --duration 60 --output perf-results.json

# Append to baseline history
node scripts/perf-baseline-archive.mjs perf-results.json

# Compare current run vs rolling 14-day p95 (warns if any subsystem regresses >25%)
node scripts/perf-baseline-compare.mjs perf-results.json --window 14
```

## CI wiring (deferred to follow-up plan F3 wiring step)

`.github/workflows/perf.yml` currently runs only the measurement step. Wiring archive + compare into CI requires `actions/cache/restore@v4` + `actions/cache/save@v4` to persist `history.jsonl` across cron runs. See `docs/plans/wiring/post-r1-r6-followups-plan-2026-05-07.md` (F3 → CI wiring section) for the template.

Until wired, `history.jsonl` is generated only by ad-hoc local runs.
